지원금헌터 사이트 (월별 '지원금 총정리' 정적 사이트)  — 홈피 봇 제작 2026-11-12
■ 목적: 인스타 @jiwongeum_hunter DM 링크가 가는 외부 페이지. 월별 총정리 + 항목 페이지. 검색 유입을 쌓아 나중에 AdSense.
■ 만들기: node 만들기.js (결과/ 에 생성) · 화면 확인: SITE_DEMO=1 node 만들기.js (예시 데이터, noindex) + node 미리보기.js
■ 내용 채우는 법(지원금헌터 방): 자료/월별/YYYY-MM.json 한 파일이 한 달 총정리다.
  { "월":"2026-12", "제목":"12월 지원금 총정리", "확인일":"2026-11-30", "머리말":"(선택)",
    "항목":[ { "id":"영문숫자-_ 만", "분류":"청년|주거|가족…", "이름":"", "기관":"", "금액":"", "대상":"", "기간":"2026-12-15 또는 상시",
               "신청":"", "주의":"", "링크":"https://원문", "확인일":"2026-11-30", "요약":"한두 문장" } ] }
  필수: id·이름·링크(https 원문)·확인일. 하나라도 없으면 그 항목은 자동으로 빠진다. 값을 모르면 칸을 비워 두면 그 줄이 안 나온다(지어내지 않는다).
  원문 확인한 것만 — 카드마다 '원문확인 M/D' 빨간 도장이 붙는다.
■ 첫 화면은 가장 최근 월. 지난 달은 자동으로 /archive/ 로 간다.
■ 광고: 자료/광고.json 에 애드센스 ca-pub 과 슬롯 번호를 넣으면 상단·중간·하단 자리가 켜진다(비어 있으면 코드도 자리도 없음). 승인 전에는 비워 둔다.
■ 주소·도메인: 자료/사이트.json 의 주소·도메인. 도메인이 정해지면 채우고(CNAME 자동), GitHub Pages + 가비아 DNS 연결.
■ 공개 전 영감 확인: 도메인, 운영자 정보(지금은 아티스트 코치와 같은 사업자 임시값), 첫 총정리 내용.
